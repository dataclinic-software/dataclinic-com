Three simple steps

Connect the card

Use a card reader on your Windows PC. Only removable cards show up — your PC's own drives are never touched.

Scan

A quick scan finds recently deleted files with their names; a deep scan finds photos and videos on a formatted card or one with a damaged file table.

Save

Preview what was found and save it to a different drive — never back onto the card.

Honest about what it finds

  • Every photo checked all the way through. Damaged photos are marked as damaged and shown as they'll actually be saved — never as a clean thumbnail.
  • Warns you about a failing card. If many photos on a card are damaged, the app tells you the card itself may be failing and to stop using it.
  • Read-only. It never writes to, repairs or formats the card being scanned.

Deep scan recognises 17 formats

Photos: JPEG, PNG, GIF, TIFF, HEIC · Raw: Canon CR2 and CR3, Nikon NEF, Sony ARW, Adobe DNG · Video: MP4, MOV, AVI · Audio: MP3, WAV · Documents: PDF, Word (.docx).

Overwritten photos are gone

Stop using the card straight away — every new photo can overwrite one you're trying to recover.

Deep scan finds no names

Files found by a deep scan come back without their original names or folders, and fragmented videos can come back incomplete.

Physical failure needs a lab

A card that shows 0 MB, isn't recognised or gives constant errors has failed in hardware — no software can fix that.

Files on a hard drive, SSD or USB stick?

USB sticks hold many file types the card tool doesn't look for — spreadsheets, presentations, archives. Use Recovery for Hard Drives instead: free to scan and preview.

Questions

Is it really free?

Yes — no trial, no upsell inside the app, no registration.

Which cards does it work on?

SD and microSD memory cards formatted FAT32 or exFAT, which is how virtually all camera, drone and phone cards are formatted. Connect the card with a card reader.

Will it work on a USB stick, hard drive or SSD?

No — it's built for memory cards only and won't even show your PC's own drives. For USB sticks, hard drives and SSDs, use Recovery for Hard Drives (a card in a USB card reader can also be scanned there).

Which file types can it recover?

A quick scan recovers any type of deleted file the card's file table still lists, with its original name and folder. A deep scan — for formatted cards and damaged file tables — recognises 17 formats: JPEG, PNG, GIF, TIFF, HEIC, CR2, CR3, NEF, ARW, DNG, MP4, MOV, AVI, MP3, WAV, PDF and Word (.docx). Deep-scan results come back without their original names.

Some of my photos are marked as damaged. Why?

Every photo found by a deep scan is checked all the way through. Damaged photos are marked as damaged and shown as they'll actually be saved, never as a clean thumbnail. If many photos on a card are damaged, the card itself may be failing — the app tells you to stop using it.

Is there a Mac version?

Not yet — it runs on Windows 10 and 11 (64-bit).

Why does Windows show a warning when I run it?

That's Microsoft SmartScreen, which is cautious about newly released software whoever published it. The installer is digitally signed by Data Clinic Ltd — click “More info”, check the publisher says Data Clinic Ltd, then “Run anyway”.

My card shows 0 MB or isn't recognised.

That's usually physical failure, which no software can fix — and trying more tools can make things worse. Stop using the card. Data Clinic's own lab is in the UK (dataclinic.co.uk). Elsewhere, take the drive to a professional data recovery lab near you — and stop using it until then.

Installing

  1. Install on a different drive from the one you're recovering. Never download or install recovery software onto the drive with the lost files — the installer could overwrite them.
  2. Run the installer. Windows asks for permission because the software reads drives directly. Check that the verified publisher shows Data Clinic Ltd.
  3. If Microsoft SmartScreen appears ("Windows protected your PC"), click More info, check the publisher says Data Clinic Ltd, then Run anyway. SmartScreen is cautious about newly released software whoever published it; every new version is submitted to Microsoft.
  4. Updating. When Recovery for Hard Drives starts online, it tells you if a newer version is available. Install the new version over the old one; your licence key carries over.

To check a download, run certutil -hashfile <file> SHA256 in Command Prompt and compare the result with the checksums above.

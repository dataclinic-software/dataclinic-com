Guide

Can deleted files be recovered from an SSD?

Short answer: Usually not. Most SSDs use TRIM: when you delete a file, Windows tells the drive the space is free and the drive erases it, typically within minutes. A quick format on an SSD erases the whole drive the same way. What can often be recovered from an SSD is data lost another way — a damaged file system, a drive showing as RAW, or a partition that's gone missing.

What TRIM does

An SSD can't simply overwrite old data; it has to erase blocks before reusing them. To keep the drive fast, Windows sends a TRIM command for deleted space, and the SSD clears it in the background. Once that happens, the deleted file is gone — for any software and any lab.

When SSD recovery is possible

  • Damaged or RAW file systems — the files weren't deleted, just made unreadable. RAW drive guide →
  • A lost or deleted partition where the data area hasn't been trimmed.
  • Some external SSDs and older systems where TRIM wasn't passed through. Many modern USB enclosures do pass it, so don't count on this.

Check, rather than guess

Recovery for Hard Drives scans SSDs and checks each deleted file it finds. Files the drive has already erased are marked “erased by the drive”, so you can see what's genuinely recoverable before you pay — the scan and preview are free.

If the SSD is the one Windows runs from, take it out and connect it to another PC — the software never scans the running system drive.

Protect yourself next time

Because SSD deletions are so final, a backup is the only reliable protection: File History or another backup tool, plus a cloud service with a deleted-files folder.

Questions

Does a lab have special tools to undo TRIM?

No. Once an SSD has erased the blocks, the data no longer exists on the chips.

Is TRIM always on?

On Windows 10 and 11 with an internal SSD, almost always. Some external enclosures and older systems don't pass it through.

Can I recover files from a formatted SSD?

Usually not — a quick format on an SSD trims the whole drive.

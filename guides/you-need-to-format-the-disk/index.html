Guide

“You need to format the disk in drive E: before you can use it”

Short answer: Click Cancel. This message means Windows can't read the drive's file system — not that the files are gone. Formatting would make recovery much harder. Work out which of the causes below applies, then copy the files off with recovery software before you format anything.

The usual causes

  1. The drive was formatted on a Mac (APFS or HFS+). Windows can't read it, so it offers to format it. Nothing is wrong with the drive. Read it on Windows →
  2. The file system is damaged — often after unplugging the drive while it was busy, or a power cut. The files are usually intact. RAW drive guide →
  3. The drive is failing and can't read its own file table. Look for the warning signs below.
  4. It's encrypted with BitLocker or another tool and hasn't been unlocked.
Stop if the drive is physically failing. Clicking, grinding or beeping, a drive Windows doesn't detect or shows as 0 MB, or one that keeps disconnecting has a hardware fault. Running any software on it can make things worse — read this first.

Get the files off safely

  1. Download and install Data Clinic Recovery for Hard Drives on a different drive from the one you're recovering.
  2. Choose drive. Connect the drive and choose it in the list. The software reads the drive's health report straight away; if the drive reports failure, it stops there.
  3. Look for files. Run the recommended scan. The software reads file systems Windows can't — damaged NTFS, exFAT and FAT32, and Mac APFS, HFS+ and HFS — and shows files with their names. If the file table is badly damaged, use a deep scan.
  4. Pick files. Browse the results with previews, folders and filters, and tick what you want. Every file shows whether it can really be recovered. Scanning and previewing are free.
  5. Save files to a different drive. This is the only step that needs a licence.

A USB stick that shows this message is usually a damaged file system too — that's exactly what the deep scan is for. But a stick that shows 0 MB or keeps disconnecting has failed physically; software can't fix that.

After your files are safe

Once everything you need is copied to another drive, formatting the drive will make it usable again — if its health report is good. If the software reported warning signs, replace the drive instead.

Questions

If I click Format, are my files gone?

A quick format makes recovery harder but often still possible — stop using the drive and run a deep scan. A full format overwrites everything.

Why does this happen to a drive that worked yesterday?

Most often it was unplugged while Windows was writing to it, or it was used on a Mac. Sometimes it's the first sign of a failing drive.

Can CHKDSK fix it?

It can make it worse. Get the files off first.

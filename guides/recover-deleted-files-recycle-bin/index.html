Recover files deleted from the Recycle Bin or with Shift+Delete

Short answer: Emptying the Recycle Bin or pressing Shift+Delete doesn't wipe a file straight away on a hard drive: Windows marks the space as free, and the file stays there until something new is written over it. Stop using the drive, check the backups below, then scan the drive with recovery software from a different computer or drive. On an SSD, the honest answer is different — see the limits.

First: check the places Windows keeps copies

  • The Recycle Bin itself, if you haven't emptied it: right-click the file and choose Restore.
  • OneDrive, Google Drive or Dropbox: each has its own recycle bin or deleted-files view on the website, usually keeping files for 30 days or more.
  • File History or a backup drive: right-click the folder the file was in and choose Properties → Previous Versions.

Then stop writing to the drive

Every file you save, download or install could land on the space your deleted file still occupies. Don't install recovery software on that drive, and don't save recovered files back onto it.

Was the file on your C: drive? Recovery for Hard Drives never scans the drive Windows is running from — reading and writing to it all the time would put your files at risk. Shut the computer down, take the drive out and connect it to another Windows PC with a USB adapter, where it can be scanned safely. If that isn't practical, ask someone who can, or a professional.

Honest limits

  • Overwritten files are gone. If new data has been written over a deleted file, no software can bring it back. The software marks such files rather than pretending.
  • SSDs usually erase deleted files within minutes. Most laptops now use SSDs, which clear deleted data themselves (TRIM). The software checks and marks those files “erased by the drive”. Why SSDs are different →
  • Recovered files carry today's date, not their original date.

Questions

Does Shift+Delete delete a file permanently?

It skips the Recycle Bin, but on a hard drive the data stays where it was until it's overwritten, so it can often be recovered. On an SSD it's usually erased by the drive within minutes.

How long do I have to recover a deleted file?

On a hard drive, until something overwrites it — which could be minutes on a busy system drive, or months on an external drive you don't use. Stop using the drive as soon as you notice.

Can I recover deleted files without software?

Only from a copy: the Recycle Bin, a cloud service's deleted-files folder, File History or another backup. Once those are empty, you need recovery software.

Is the scan free?

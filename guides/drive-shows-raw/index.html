Drive showing as RAW? Get your files back without formatting

Short answer: A drive shows as RAW when Windows can't recognise its file system — usually because the file system is damaged, the drive was unplugged mid-write, or it's formatted in a way Windows doesn't read (such as a Mac drive). The files are normally still there. Don't format it and don't run CHKDSK; scan it with recovery software and copy the files to another drive.

Why drives go RAW

  • Damaged file system — often after the drive was unplugged without “Safely remove”, or a power cut.
  • A Mac-formatted drive (APFS or HFS+) plugged into Windows. Windows shows it as RAW or unreadable — the drive is fine. Read a Mac drive on Windows →
  • A failing drive that can't read its own file table. If it's slow, clicking, or disconnecting, that's the cause.
Stop if the drive is physically failing. Clicking, grinding or beeping, a drive Windows doesn't detect or shows as 0 MB, or one that keeps disconnecting has a hardware fault. Running any software on it can make things worse — read this first.

What not to do

  • Don't click “Format disk” when Windows offers.
  • Don't run CHKDSK. Windows may suggest it, and it sometimes “fixes” a damaged file system by discarding the parts it doesn't understand — including your files.
  • Don't initialise or repartition the drive in Disk Management.

Recover the files

  1. Download and install Data Clinic Recovery for Hard Drives on a different drive from the one you're recovering.
  2. Choose drive. Connect the drive and choose it in the list. The software reads the drive's health report straight away; if the drive reports failure, it stops there.
  3. Look for files. Start with the recommended scan. A quick scan can read file tables Windows has given up on — including Mac APFS, HFS+ and HFS — and lists files with their names and folders. If the file table is too damaged, a deep scan reads the whole drive and finds files by their content.
  4. Pick files. Browse the results with previews, folders and filters, and tick what you want. Every file shows whether it can really be recovered. Scanning and previewing are free.
  5. Save files to a different drive. This is the only step that needs a licence.

Once your files are safely copied off, you can format the drive and use it again — if its health report is good.

Honest limits

  • If the drive is RAW because it's failing, software is the wrong tool — the drive needs a lab. Data Clinic's own lab is in the UK (dataclinic.co.uk); elsewhere, choose a professional data recovery lab near you.
  • BitLocker-encrypted drives can look RAW too; Recovery for Hard Drives can't read BitLocker.

Questions

Can I fix a RAW drive without losing data?

Copy the files off first, with recovery software, then format the drive. Trying to “fix” it in place risks the files.

Will CHKDSK fix a RAW drive?

Usually it reports that it can't run on RAW drives. When it does run on a damaged drive, it can delete what it can't make sense of — so don't use it before your files are safe.

My external drive shows RAW on Windows but works on a Mac.

Then it's Mac-formatted. Windows can't read APFS or HFS+, but Recovery for Hard Drives can, and can copy the files onto a Windows drive.

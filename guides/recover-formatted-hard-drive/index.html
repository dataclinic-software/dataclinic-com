Recover files from a formatted hard drive

Short answer: A quick format only rebuilds the drive's file table; the files themselves usually stay on the drive until they're overwritten. Stop using the drive, don't copy anything onto it, and run a deep scan. A full format in Windows 10 or 11 writes zeros over the whole drive — after that, nothing is recoverable.

What not to do

  • Don't copy files back onto the drive or start using it again — that overwrites the old data.
  • Don't format it again, “just to be sure”, and don't run a full format.
  • Don't run disk repair tools such as CHKDSK. They write to the drive.
Stop if the drive is physically failing. Clicking, grinding or beeping, a drive Windows doesn't detect or shows as 0 MB, or one that keeps disconnecting has a hardware fault. Running any software on it can make things worse — read this first.

Quick format or full format?

Windows' Quick Format box is ticked by default. A quick format writes a new, empty file table and leaves the rest of the drive alone — which is why recovery usually works. A full format (unticking Quick Format) also writes zeros to every sector on Windows Vista and later; that data is gone for good.

The file system matters too:

  • NTFS (most Windows drives): a format clears the file table, so file names and folders can't come back. A deep scan finds files by their content and gives them numbered names such as Rescued_0001.jpg, in a folder called [Found by content].
  • exFAT and FAT32 (many external drives and USB sticks): after a quick format, the old folder listings often survive. The deep scan finds them and brings many files back with their names, under [Old folder listings] — except files that sat in the drive's top folder.
  • SSDs: a quick format erases the whole drive (TRIM). Formatted SSDs are usually not recoverable.

Recover the files

  1. Download and install Data Clinic Recovery for Hard Drives on a different drive from the one you're recovering.
  2. Choose drive. Connect the drive and choose it in the list. The software reads the drive's health report straight away; if the drive reports failure, it stops there.
  3. Look for files. Choose deep scan (under “Other ways”). It reads the drive's file tables first — so anything they still list keeps its name — then reads the whole drive and recognises files by their content. On a large drive this takes hours; you can stop at any time and keep what's been found.
  4. Pick files. Browse the results with previews, folders and filters, and tick what you want. Every file shows whether it can really be recovered. Scanning and previewing are free.
  5. Save files to a different drive. This is the only step that needs a licence.

Honest limits

  • Anything copied onto the drive since the format has overwritten something.
  • Large videos are often stored in fragments; a deep scan may recover them incomplete.
  • Files found only by content have no original names or folders.

Questions

Can a formatted hard drive be recovered?

Usually, after a quick format, if nothing much has been written to it since. After a full format in Windows Vista or later, no — the data has been overwritten with zeros.

Why are my recovered files called Rescued_0001?

On an NTFS drive, formatting clears the file table where names are kept. Files found by their content alone come back with numbered names.

I reinstalled Windows on the drive. Can I still recover files?

Some, sometimes — but installing Windows writes many gigabytes, so a lot will have been overwritten. Take the drive out and scan it from another PC.

Does it work on a formatted SSD?

Usually not. A quick format on an SSD tells the drive to erase everything, and it does.

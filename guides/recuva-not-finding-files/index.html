Recuva not finding your files? Why, and what to try next

Short answer: When Recuva comes back empty, the reason usually matters more than the program. Files that have been overwritten, or deleted from an SSD, are gone and no other tool can change that. But if you only ran the normal scan, filtered by file type, or the drive was formatted, shows as RAW or came from a Mac, a deep scan or a tool that reads the drive differently can often find more. Stop writing to the drive first — and if it clicks, stalls or disconnects, stop altogether.

Do this first

  • Stop writing to the drive. Don't install anything on it, save to it, or keep using it. Each write can land on the files you want.
  • Listen to it. Clicking, beeping, a scan that crawls or freezes at the same point, or a drive that drops out of Windows are signs of a physical fault.
Stop if the drive is physically failing. Clicking, grinding or beeping, a drive Windows doesn't detect or shows as 0 MB, or one that keeps disconnecting has a hardware fault. Running any software on it can make things worse — read this first.

Match what happened to the closest cause. Some are worth a second try; some aren't, and it's better to know that before you pay for anything.

Files that won't open after recovery were usually partly overwritten, stored in fragments, or read from a drive that is starting to fail. Recuva colours each result — "green for excellent, orange for acceptable, and red for unlikely" — and doesn't show previews for images it likely can't recover (CCleaner support). Red results rarely improve in another program.

What not to do

  • Don't install the next tool on the same drive, or save recovered files back onto it.
  • Don't run scan after scan with different programs on a drive that is slow, noisy or disconnecting. Each pass works failing hardware harder.
  • Don't format the drive or run CHKDSK to “fix” it first. Both write to it.

Questions

Why does Recuva say it found no files?

Usually because the files were overwritten, the drive is an SSD that has erased them, the scan was limited to one file type or the wrong drive, or the drive was formatted, is RAW or came from a Mac. Only the last few are worth another try.

Should I turn on Recuva's Deep Scan?

Yes, once, if the drive is healthy and the normal scan came up short. Recuva's help says it is set in the Options dialog and can take hours. Don't run it on a drive that clicks or keeps disconnecting.

What do Recuva's green, orange and red dots mean?

Recuva's help describes them as excellent, acceptable and unlikely chances of recovery. Red files have usually been at least partly overwritten, and another program is unlikely to do better.

Can another program find files Recuva missed?

Sometimes — mainly on formatted, RAW or Mac-formatted drives, where a different scan method or file system support makes the difference. Never for overwritten files or files an SSD has erased. With Recovery for Hard Drives the scan and preview are free, so you can check before you pay.

Recuva recovered my files but they won't open. Why?

They were probably partly overwritten, stored in fragments, or read from a drive that is starting to fail. If the drive has been slow or noisy, stop using it and read the signs of a failing drive.

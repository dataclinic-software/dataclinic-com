Read a Mac drive on Windows and copy your files off

Short answer: Windows can't read drives formatted on a Mac (APFS, HFS+ or HFS), so it shows them as unreadable or asks you to format them — don't. The drive is fine. Recovery for Hard Drives reads Mac drives on Windows and copies the files onto a Windows drive, including files the Mac had deleted where an old copy of the file table survives.

Why Windows can't open it

Macs use their own file systems: APFS on recent Macs and HFS+ (“Mac OS Extended”) on older ones and many Time Machine drives. Windows has no built-in support for either, so it reports the drive as RAW or says you need to format it. Click Cancel.

Copy the files off on Windows

  1. Download and install Data Clinic Recovery for Hard Drives on a different drive from the one you're recovering.
  2. Choose drive. Connect the drive and choose it in the list. The software reads the drive's health report straight away; if the drive reports failure, it stops there.
  3. Look for files. Run a quick scan. It reads APFS, HFS+ and HFS directly and lists every file still on the drive, with names and folders. Deleted Mac files come back with their names where an old copy of the file table survives (APFS and HFS+).
  4. Pick files. Browse the results with previews, folders and filters, and tick what you want. Every file shows whether it can really be recovered. Scanning and previewing are free.
  5. Save files to a different drive. This is the only step that needs a licence.

Recovered files are saved to a Windows drive (NTFS or exFAT), ready to use straight away.

Limits

  • FileVault-encrypted volumes are identified but can't be read.
  • A few files Apple stores compressed may not come back; APFS Fusion Drives need a lab.
  • The software runs on Windows only — a Mac edition isn't available yet.

If you only need to move files between a Mac and a PC in future, format a drive as exFAT — both systems read and write it.

Questions

Can Windows read a Mac hard drive?

Not without extra software. Windows doesn't support APFS or HFS+.

Can I recover deleted files from a Mac drive on Windows?

Often, yes: deleted Mac files come back with their names where an old copy of the file table survives (APFS and HFS+). If the Mac drive is an internal SSD, deleted files are usually erased by the drive itself.

Will it change anything on the Mac drive?

No. It reads the drive strictly read-only and saves files to a different drive.

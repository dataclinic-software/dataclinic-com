Formatted a USB stick by mistake? How to get the files back

Short answer: If you quick-formatted a USB stick, your files are usually still on it — and because most sticks use exFAT or FAT32, many can come back with their original names. Stop using the stick, don't copy anything onto it, and run a deep scan.

Why sticks are often recoverable

A quick format writes a fresh, empty file table. On exFAT and FAT32 — how most USB sticks come — the old folder listings often survive, so the deep scan can bring many files back with their names, under [Old folder listings]. Files that sat in the stick's top folder come back without names.

Recover the files

  1. Download and install Data Clinic Recovery for Hard Drives on a different drive from the one you're recovering.
  2. Choose drive. Connect the drive and choose it in the list. The software reads the drive's health report straight away; if the drive reports failure, it stops there.
  3. Look for files. Choose deep scan (under “Other ways”). It reads the file table first, then the whole stick, finding old folder listings and recognising files by their content. Sticks have no health report, so the health check will say it's not available — that's normal.
  4. Pick files. Browse the results with previews, folders and filters, and tick what you want. Every file shows whether it can really be recovered. Scanning and previewing are free.
  5. Save files to a different drive. This is the only step that needs a licence.

When a stick has failed

A stick that shows 0 MB, isn't recognised, or keeps disconnecting has a hardware fault. Software can't fix that. A stick that Windows asks to format is different — that's usually a damaged file system, and exactly what the deep scan is for. Don't format it →

Questions

Can you unformat a USB stick?

Not in place — but you can recover the files from it onto another drive, which gets you the same result safely.

I formatted the stick and copied new files onto it.

Some old files will be overwritten. Stop now and scan; what's left may still be recoverable.

Why does the health check say “not available”?

USB sticks don't have a health report (SMART) the way hard drives do.

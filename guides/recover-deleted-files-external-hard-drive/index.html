Recover deleted files from an external hard drive

Short answer: Files deleted from an external hard drive are usually still on it until they're overwritten — and external drives are often recoverable because they're used less than the main drive. Stop copying anything onto it, check its Recycle Bin, then scan it with recovery software.

Check the Recycle Bin first — it depends on the drive

Windows treats external hard drives like internal ones: files deleted normally go to the Recycle Bin, so check there first. Files deleted from USB memory sticks skip the Recycle Bin and are deleted straight away. Either way, Shift+Delete skips it.

Stop using the drive

Don't save, copy or download anything onto it. Leave it unplugged until you're ready to scan, and save recovered files to a different drive.

Stop if the drive is physically failing. Clicking, grinding or beeping, a drive Windows doesn't detect or shows as 0 MB, or one that keeps disconnecting has a hardware fault. Running any software on it can make things worse — read this first.

Recover the files

  1. Download and install Data Clinic Recovery for Hard Drives on a different drive from the one you're recovering.
  2. Choose drive. Connect the drive and choose it in the list. The software reads the drive's health report straight away; if the drive reports failure, it stops there.
  3. Look for files. Run a quick scan: it lists deleted files the drive's file table still knows about, with their names and folders. If something's missing, a deep scan also searches the whole drive by file content. If the drive shows any warning signs, the software suggests imaging it first — copying it once to a file — so a weak drive isn't read over and over.
  4. Pick files. Browse the results with previews, folders and filters, and tick what you want. Every file shows whether it can really be recovered. Scanning and previewing are free.
  5. Save files to a different drive. This is the only step that needs a licence.

External SSDs are different

Portable SSDs often erase deleted files themselves within minutes (TRIM). The software checks every deleted file and marks those the drive has erased. More on SSDs →

Honest limits

  • Overwritten files can't be recovered by anyone.
  • A drive that clicks, isn't detected or disconnects needs a lab. Data Clinic's own lab is in the UK (dataclinic.co.uk); elsewhere, choose a professional data recovery lab near you.

Questions

Do files deleted from an external drive go to the Recycle Bin?

From an external hard drive, usually yes. From a USB memory stick, no — they're deleted immediately.

Can I recover files from an external drive that was dropped?

If it now clicks, isn't detected or makes unusual noises, don't use software — a dropped drive often has damaged heads. That's a lab job.

Does it work with Seagate, WD, Toshiba and other brands?

Yes — the brand doesn't matter for deleted files. What matters is that the drive still works.

Common questions

I bought a licence. Where's my key?

It's emailed straight after payment, usually within a few minutes. Check your spam folder. If it hasn't arrived within 30 minutes, email support@dataclinic.com with your order number.

How do I enter my licence key?

Open Recovery for Hard Drives, choose Help → Licence… (or enter it on the Save files step), paste the key and press Apply key. The key is saved per Windows user, so another account on the same PC needs it entered again.

My yearly licence renewed. Do I need a new key?

No. The program picks up the renewed key by itself the next time it starts online.

How do I cancel a yearly licence?

Use the link in the email we send before each renewal, or email support@dataclinic.com. An unwanted renewal is refunded in full if you ask within 14 days.

How do I get a refund?

Email customerservices@dataclinic.co.uk with your order number. Onelink/Stripe refunds your original payment method and the key is deactivated. See the refund policy.

Windows says “Windows protected your PC”.

That's Microsoft SmartScreen, which is cautious about new software. Click More info, check the publisher is Data Clinic Ltd, then Run anyway.

My drive doesn't appear in the list.

The drive Windows runs from never appears, by design. Other drives may be missing if Windows can't see them at all — check Disk Management. A drive Windows doesn't detect, or that shows 0 MB, is usually physically failing: stop using it. See signs of a failing drive.

The software says my drive is failing.

Stop using the drive — every further read can make things worse, and software can't fix physical failure. You can claim a full refund. Data Clinic's own lab is in the UK (dataclinic.co.uk). Elsewhere, take the drive to a professional data recovery lab near you — and stop using it until then.

How do I send a problem report?

In Recovery for Hard Drives, use the Help menu. The report includes your description and the program's technical log; you can save it to a file and read it before sending.

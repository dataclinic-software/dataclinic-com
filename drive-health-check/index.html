Questions

Is the Drive Health Check really free?

Yes. It's free to download and use, with no licence key and no time limit.

Can it damage my drive or change anything on it?

No. It never writes to, repairs or formats any drive. It reads each drive's own health report, and the optional surface test only reads. The surface test stops by itself if the drive starts struggling, and it is never offered on a drive that is already failing.

Which drives can it check?

Every drive in or attached to the PC: hard drives, SSDs (SATA and NVMe), USB drives, and the PC's own system drive.

What do the four verdicts mean?

Healthy: the drive's report shows nothing wrong. Back it up now: the report shows warning signs, so copy anything important while you still can. Stop using it: the report shows the drive is failing, and every further use can make things worse. Can't read the health report: the drive didn't pass its report through to Windows. Each verdict lists its reasons in plain words, and the full report is there for experts.

Why does it say it can't read the health report?

This is common with drives in USB cases and with memory sticks, which often don't pass the drive's health report through to Windows. It doesn't mean the drive is failing; it means the tool can't see its report.

Why does it ask for administrator permission?

Windows only lets a program read a drive's health report if it has administrator permission, so the tool asks for it when it starts.

My drive says “Stop using it”. What should I do?

Stop using the drive, and don't run recovery software on it — every further read of a failing drive can make things worse. If the files on it matter, take it to a professional data recovery lab.

Can it get my files back?

No. It only checks drive health. If the drive is healthy and you've lost files, Recovery for Hard Drives can scan for them, with a free scan and preview.

What does it send over the internet?

Nothing about your drives or files. It checks for a newer version. It can also send anonymous usage counts, but that is off unless you tick “Send anonymous usage counts to Data Clinic”. The counts say which verdicts were shown, the type of drive and how many drives, whether a surface test was started and how it ended, and which next-step button was pressed. They never include drive models, serial numbers, sizes, file names or anything you type. See the privacy policy.

Is there a Mac version?

Not yet. This first release is for Windows 10 and 11 (64-bit). A Mac version is planned after the Windows beta.

Windows says “Windows protected your PC”. Is it safe?

The installer is signed by Data Clinic Ltd. Because it's a brand-new file, Windows may show this warning until enough people have downloaded it. Click More info, check the publisher says Data Clinic Ltd, then Run anyway.

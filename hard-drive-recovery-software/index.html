What it does

Three ways to get files back

It recovers from external USB drives and sticks, and from internal drives other than the one Windows runs from.

⚡

Quick scan

Reads the drive's file tables (NTFS, exFAT, FAT32 and Mac APFS, HFS+ and HFS) and brings back any kind of file they still list — documents, email, photos, video, project files — with original names and folders, including files emptied from the Recycle Bin.

🔍

Deep scan

Reads the file tables first, then the whole drive, recognising files by their content — for formatted drives and damaged file tables. It always finds at least what a quick scan finds.

🧬

Image a struggling drive

Copies a drive showing early trouble to an image file once, so every scan works from the copy. Unreadable sectors are mapped; interrupted images resume. Imaging is free.

Deep scan recognises JPEG, PNG, GIF, TIFF, BMP, WebP, Photoshop, HEIC, Canon, Nikon, Sony and Adobe DNG raw, MP4, MOV, AVI, MKV/WebM, WMV, MP3, WAV, FLAC, M4A, WMA, Ogg/Opus, PDF, Word, Excel, PowerPoint, OpenDocument, Outlook PST/OST and MSG, ZIP, RAR, 7-Zip and ISO — and you can add signatures for your own file types.

Honest about the limits

What no software can do

Overwritten data is gone

When a drive has re-used the space a deleted file occupied, no software can bring it back. This software tells you, file by file, rather than selling false hope.

SSDs erase deleted files

On an SSD, deleted files are usually erased by the drive itself within minutes (TRIM), and a quick format erases the whole drive. The software marks such files "erased by the drive".

Encryption needs its keys

Windows EFS files come back unreadable without the original account's key. BitLocker drives can't be read. FileVault-encrypted Mac volumes are named but cannot be read.

A failing drive needs a lab

Clicking, not detected, or a health report that says failing — that's a job for a professional lab, not software. The software says so and stops. Signs of a failing drive →

Questions

Is the scan really free?

Yes. Choosing the drive, scanning, imaging, previewing files, the job report and CSV export are all free. You only need a licence at the final step, to save recovered files.

Can this software damage my drive or make things worse?

No. It opens the drive strictly read-only and never writes to, repairs or formats it. The one caution: if a drive is physically failing, any reading — by any software — makes the failing hardware work. That's why it checks the drive's own health report before every scan, and stops and tells you when it sees failure symptoms.

What's the difference between a quick scan and a deep scan?

A quick scan reads the drive's file tables — fast, with names and folders. A deep scan does the same first, then reads every sector and finds files by their content, even after a format, so it always finds at least what a quick scan finds. Files found only by content come back with numbered names like Rescued_0001.jpg in a [Found by content] folder. On a large drive a deep scan takes hours; you can stop at any time and keep what has been found.

When should I use “Image the drive first”?

Whenever a drive shows any sign of trouble — read errors, slow patches, a caution on its health report. The software reads every sector once and saves an exact copy to a file on another drive; scans then work from the copy, so the drive isn't read again and again. Imaging is free. A drive whose health report says it is failing is not imaged — that's a job for a lab.

Does it work on SSDs?

It scans them, with one honest limit: most SSDs erase deleted data themselves within minutes (TRIM), and a quick format on an SSD erases the whole drive, so deleted and formatted files are usually gone for good. The software checks each deleted file and marks any the drive has erased. Files lost to a damaged file table can still be found.

Does it read Mac drives?

Yes — APFS, HFS+ and HFS, on Windows, including files the Mac had deleted where an old copy of the file table survives (APFS and HFS+). FileVault-encrypted volumes are identified but cannot be read; APFS Fusion Drives need a lab. The software itself runs on Windows only.

Can it recover files from the drive Windows runs from?

No. To keep that drive safe, it never appears in the drive list. To recover from it, take the drive out and connect it to another Windows PC, where it shows up like any other drive.

What won't version 1.1.2 do?

It can't read BitLocker-encrypted drives, Windows dynamic disks (spanned or striped volumes), RAID arrays that need rebuilding from their member disks, or ReFS, Linux and FAT16 file systems. Recovered files are dated the day you recover them, not their original date. The deep scan doesn't find Fujifilm, Olympus or Panasonic raw files. The program needs administrator rights each time it starts, and the licence key is saved per Windows user.

Why might a recovered video not play?

Videos are big, so drives often store them in fragments. A deep scan finds a video's start but can't always reassemble scattered pieces, so a recovered video may be incomplete. That's a limit of how drives store data, not something more scanning can fix.

What does Ask Rex send over the internet?

Ask Rex is off until you turn it on. When you use it, what you type and basic job details (such as the drive's size and health and how many files were found) go through Data Clinic's server to Anthropic, the provider of the Claude AI model behind Rex. Your files, their contents and the list of file names are never sent; a file or folder name is sent only if you type it. Please don't type passwords or personal details into it.

What does the software send over the internet?

Anonymous usage counts (version 1.1.2 and later), unless you switch them off in Settings (“Send anonymous usage counts”; off until you agree if your region is in the EU/EEA): which steps you used, the drive type and health result, rough ranges of how many files were found and recovered, and error codes. Never file or folder names, file contents, drive models or serial numbers, licence keys or anything you type. Otherwise, only what you choose to send — a problem report from the Help menu, or a contact request from the failure screen — plus two small automatic checks when it starts online: whether a newer version is available (nothing about you or your drives), and, if a licence key is entered, the key and version to check whether it has been renewed or refunded. And, if you turn it on, Ask Rex as described above. It never sends the contents of your files. See the privacy policy.

Do I need to be online?

No. The licence key is verified on your PC. You need to be online only to buy — and, for a yearly licence, the program picks up your renewed key by itself the next time it starts online.

My drive is clicking or isn't detected. Will this help?

No — those are physical faults, and running any software on the drive can make things worse. Stop using it and take it to a professional data recovery lab.
